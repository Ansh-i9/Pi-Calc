## README

This README file will help you understand this repository and my project.

### Issue

Most calculators are thrown into dumps when they stop working. Many of them are not recycled, even after several years.

I questioned myself: *Why are most calculators thrown away and not recycled for such a long time?*

### Components Used

* Raspberry Pi Pico 2W **or** ESP32 Wi-Fi Module
* LCD Display Module with I2C Interface
* Tactile Push Button Switch

### Objective

* To reduce electronic waste caused by discarded calculators

* To promote recycling and reuse of electronic components

* To create a functional and low-cost system using microcontrollers

* To spread awareness about sustainable electronics and responsible disposal
